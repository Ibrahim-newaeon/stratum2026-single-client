Integration requirements

What each platform needs before it can be connected. Scopes and credential names match what the backend actually requests, so this is the list to gather against — not the vendor marketing page. The Before you connect notes are the failures that only show up after a connection has already been attempted.

Ad platforms

Meta Ads

Business Manager ad accounts — campaign sync, insights, Conversions API.

OAuth 2.0

Credentials

App ID
App the OAuth dialog runs against. META_APP_ID
App Secret
Token exchange + webhook signature verification. META_APP_SECRET
Ad account IDs
Comma-separated. META_AD_ACCOUNT_IDS

Scopes requested

  • ads_management
  • ads_read
  • business_management
  • pages_read_engagement

Before you connect

  • App must be in Live mode — Development mode returns data only for app admins.
  • Connecting user needs an admin role on the Business Manager owning the ad account.
  • Advanced Access for ads_management is required to serve non-admin users.

Google Ads

Campaign structure, spend and conversion metrics.

OAuth 2.0

Credentials

Client ID
Google Cloud OAuth 2.0 Web application credential. GOOGLE_ADS_CLIENT_ID
Client Secret
Paired with the client ID. GOOGLE_ADS_CLIENT_SECRET
Developer token
Separate from OAuth. Every call fails without it — the field most often missed. GOOGLE_ADS_DEVELOPER_TOKEN
Customer ID
10 digits, no dashes. GOOGLE_ADS_CUSTOMER_ID

Scopes requested

  • https://www.googleapis.com/auth/adwords

Before you connect

  • Developer token needs Basic Access or higher — a Test-Access token only reaches test accounts.
  • Reading through a manager account requires login-customer-id set to that MCC.

TikTok Ads

Advertiser accounts, campaigns and reporting via the Marketing API.

OAuth 2.0

Credentials

App ID
TikTok for Business developer portal. TIKTOK_APP_ID
App Secret
Paired with the app ID. TIKTOK_SECRET
Advertiser ID
Account to sync. TIKTOK_ADVERTISER_ID

Scopes requested

  • advertiser.read
  • advertiser.write
  • campaign.read
  • campaign.write
  • report.read

Before you connect

  • App must be approved for the Marketing API — an unapproved app authorises successfully and then returns empty advertiser lists.
  • Redirect URI must match the portal entry exactly, including trailing slash.

Messaging

WhatsApp Business

Cloud API messaging. Not an OAuth flow — credentials are configured directly.

Access token

Credentials

Phone number ID
Sending number registered on the Cloud API. WHATSAPP_PHONE_NUMBER_ID
Access token
System user token. Short-lived tokens expire in 24h — use a permanent one. WHATSAPP_ACCESS_TOKEN
Business account ID
The WABA owning the number. WHATSAPP_BUSINESS_ACCOUNT_ID
Verify token
A string you choose; Meta echoes it during webhook verification. Required whenever a phone number ID is set. WHATSAPP_VERIFY_TOKEN
App secret
Validates inbound webhook signatures. WHATSAPP_APP_SECRET

Before you connect

  • Number must be registered on the Cloud API — an app-linked number alone is not enough.
  • Messages outside the 24-hour service window require a pre-approved template.
